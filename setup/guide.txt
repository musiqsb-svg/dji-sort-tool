DJI 타입 정리기 {VERSION}
DJI 카메라·드론으로 찍은 영상과 사진을 촬영일별 폴더로 정리하는 Windows 무료 프로그램입니다.

※ DJI가 만든 정식 프로그램이 아닙니다. 개인(이중필름)이 만든 비공식 프로그램이며 DJI와는 관련이 없습니다.
   (1.2까지의 이름은 'DJI정리툴'입니다. 같은 프로그램이라 그 위에 그대로 업데이트됩니다)


■ 설치 — 'DJI 타입 정리기 설치.exe'를 실행하고 [설치하기]

  · 관리자 권한이 필요 없습니다. 이전 버전이 있으면 그대로 업데이트됩니다 (설정 유지).
  · "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누르세요.
    코드 서명 인증서가 없는 무료 프로그램이라 뜨는 창입니다.


■ 사용

  1. SD카드 내용을 PC 폴더로 복사합니다.   ← 꼭 '복사한 폴더'를 정리하세요
  2. DJI 타입 정리기를 열고, 복사한 폴더를 창에 끌어다 놓습니다.
     (폴더 우클릭 › 'DJI 타입 정리기로 정리'도 됩니다. Windows 11은 '더 많은 옵션 표시' 안)
  3. 미리보기를 확인하고 [정리 시작]. 마음에 들지 않으면 [되돌리기].

  복사한 폴더
  ├ 260823_DATA_34.1G           ← 촬영일 + 용량
  │  ├ 260823_Footage           원본 영상
  │  ├ 260823_Proxy             프록시 (LRF → 원본이름_Proxy.MP4, Premiere에서 바로 연결)
  │  ├ 260823_Audio             분리 녹음 오디오 (AAC)
  │  └ 260823_Photo\jpg, dng    사진
  └ 260825_DATA_412M …

  · 결과를 확인할 때까지 원본 카드나 백업본을 지우거나 포맷하지 마세요.
  · 정리 규칙이 없는 파일(비행기록 SRT, 360 영상 등)은 그대로 둡니다.


■ 제거 — 'DJI 타입 정리기 제거.exe'를 실행하고 [제거하기]

  · [설정 › 앱 › 설치된 앱]에서 제거해도 같습니다.
  · 정리해 둔 영상·사진 폴더는 그대로 남습니다.
